# Plan 12-01: Immutable Snapshot Storage Engine (Zero-Repainting Live Mode)

## Goal
Implement a point-in-time immutable snapshot storage engine (`irai_live_snapshots`) in SQLite to eliminate retrospective recalculations (repainting) caused by session open price re-anchoring at B3 (09:00 BRT) and NYSE (10:30 BRT) opens.

<action>
Modify `backend/api/main.py`:
1. In `_get_series_data_sync(target, session_date, version, timeframe)`:
   - Accept query parameter `mode` (`live` | `recalculated`, default `live`).
   - If `mode == 'live'`:
     - Query `get_live_snapshots(conn, target, session_date, timeframe)`.
     - If live snapshots exist and cover the session, format and return them directly (`is_live_mode=True`).
     - If live snapshots are missing/incomplete for today, fallback to `engine.compute_from_db()`, save generated snapshots to `irai_live_snapshots`, and return them.
   - If `mode == 'recalculated'`:
     - Run `engine.compute_from_db()` on-the-fly (existing behavior).
</action>
