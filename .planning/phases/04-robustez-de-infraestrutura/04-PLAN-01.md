<objective>
Criar o helper `_add_column(conn, sql)` em `backend/db.py`, aplicá-lo em todas as migrações com `ALTER TABLE ADD COLUMN`, e adicionar `init_db()` ao startup da API e do Collector para que o sistema auto-heal schema no boot — com proteção contra race conditions.
</objective>

<must_haves>
- Helper `_add_column(conn, sql)` que captura `duplicate column` silenciosamente
- Todas as funções `migrate_*` que fazem `ALTER TABLE ADD COLUMN` usam o wrapper
- `migrate_divergence_config` troca `except Exception` genérico por captura específica via `_add_column`
- API lifespan chama `init_db()` antes de criar o IRAIEngine
- Collector `main()` chama `init_db()` antes do loop principal
- Nenhuma função de cálculo ou endpoint é alterada
</must_haves>

<action>
Adicionar a seguinte função **logo após** `init_db()` (depois da L152, antes de `migrate_delta`):

```python
def _add_column(conn, sql):
    """Executa ALTER TABLE ADD COLUMN de forma idempotente.
    
    Captura 'duplicate column' silenciosamente para suportar
    inicialização concorrente (API + Collector em boot simultâneo).
    Retorna True se a coluna foi adicionada, False se já existia.
    """
    try:
        conn.execute(sql)
        return True
    except sqlite3.OperationalError as exc:
        if "duplicate column" not in str(exc).lower():
            raise
        return False
```
</action>

<acceptance_criteria>

- A função contém `except sqlite3.OperationalError` (NÃO `except Exception`)
- A função contém `"duplicate column" not in str(exc).lower()`
- A função retorna `True` ou `False`
</acceptance_criteria>
</task>
